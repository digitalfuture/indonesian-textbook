# Индонезийский учебник - Руководство по запуску

## Требования

- Node.js 20.17.0 или выше
- npm или yarn

## Установка и запуск

### 1. Установка зависимостей

```bash
cd indonesian-textbook
npm install
```

### 2. Запуск в режиме разработки

```bash
npm run dev
```

Приложение будет доступно по адресу: http://localhost:5173/

### 3. Сборка для продакшена

```bash
npm run build
```

### 4. Предварительный просмотр продакшен сборки

```bash
npm run preview
```

## Особенности приложения

### Метод Дмитрия Петрова

Приложение построено по принципу "Индонезийский за 16 уроков" Дмитрия Петрова:

- **16 последовательных уроков** от простого к сложному
- **Грамматические таблицы** с основными конструкциями
- **Частотный словарь** (500 самых важных слов)
- **Интерактивные упражнения** для закрепления материала
- **Система прогресса** с достижениями

### Технологии

- **Vue 3** - реактивный фреймворк
- **TypeScript** - типизация
- **Pinia** - управление состоянием
- **Vue Router** - навигация
- **Vite** - быстрая сборка

### Функционал

1. **Уроки** - теория, примеры, упражнения
2. **Грамматика** - таблицы местоимений, времён, предлогов и др.
3. **Словарь** - поиск, фильтрация, отметка изученных слов
4. **Упражнения** - перевод, выбор ответа, заполнение пропусков
5. **Прогресс** - статистика, достижения, экспорт/импорт данных

## Разработка

### Горячая перезагрузка

Vite автоматически обновляет приложение при изменении файлов.

### Проверка типов

```bash
npm run type-check
```

### Форматирование кода

Рекомендуется использовать Prettier и ESLint для поддержания стиля кода.

## Поддержка

При возникновении проблем:

1. Убедитесь, что все зависимости установлены: `npm install`
2. Проверьте версию Node.js: `node --version`
3. Очистите кэш: `rm -rf node_modules package-lock.json && npm install`
