# Рабочий процесс

После выполнения каждой задачи необходимо выполнять следующие шаги:

1. **Увеличение версии** — обновить поле `version` в `package.json` (semver).
2. **Сборка** — запустить `npm run build` для проверки качества сборки (typecheck + vite build).
3. **Пуш** — закоммитить изменения и запушить в `origin/main`.

GitHub Actions автоматически задеплоит сборку на GitHub Pages после пуша.
