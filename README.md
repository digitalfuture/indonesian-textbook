# 🇮🇩 Индонезийский язык за 16 уроков

Интерактивный учебник индонезийского языка, созданный по методу Дмитрия Петрова.

## 🚀 Быстрый старт

### Запуск локально

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev
```

Приложение будет доступно по адресу: http://localhost:5173/

### Сборка для продакшена

```bash
npm run build
```

## 📚 Что внутри?

### 16 последовательных уроков

От простого к сложному - от знакомства до сложных грамматических конструкций.

### Грамматические таблицы

- Личные местоимения
- Времена и аспекты
- Отрицания
- Предлоги
- Вопросительные слова
- Союзы
- Модальные глаголы
- Числа и счёт

### Частотный словарь

500 самых важных слов с категориями, поиском и фильтрацией.

### Интерактивные упражнения

- Перевод предложений
- Выбор правильного ответа
- Заполнение пропусков

### Система прогресса

- Отслеживание изученных слов
- Статистика по урокам
- Достижения
- Экспорт/импорт прогресса

## 🛠 Технологии

- **Vue 3** - реактивный фреймворк
- **TypeScript** - типизация
- **Pinia** - управление состоянием
- **Vue Router** - навигация
- **Vite** - быстрая сборка

## 🌐 Деплой на GitHub Pages

Подробная инструкция в файле [DEPLOY.md](./DEPLOY.md).

Кратко:

1. Создайте GitHub репозиторий
2. Инициализируйте Git и запушите код:
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git remote add origin https://github.com/USERNAME/indonesian-textbook.git
   git push -u origin main
   ```
3. Включите GitHub Pages in Settings > Pages > Source: GitHub Actions
4. Workflow автоматически задеплоит сайт после каждого пуша
